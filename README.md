# React Developer Portfolio

A responsive personal portfolio built with React and Vite. It includes About, Projects, Skills, Resume, and Contact sections.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build and local verification
```bash
npm run build
npm run preview
```
Vite writes the optimized production site to `dist/`. `npm run preview` serves that production output locally. Check every navigation link, project link, contact email, resume download, and mobile layout before deployment.

## Performance
- The Contact section is loaded with `React.lazy()` and `Suspense`.
- The Vite production build minifies JavaScript with esbuild and minifies CSS.
- The browser can cache versioned production assets generated by Vite.
- Add `loading="lazy"` to any content images you add below the fold. Prefer compressed WebP/AVIF images with explicit width and height.

## Personalize before publishing
1. Replace `Your Name` in `src/App.jsx` and the footer.
2. Update email, GitHub, and LinkedIn URLs.
3. Replace sample project descriptions and repository URLs with your real work.
4. Add your PDF resume at `public/resume.pdf`.
5. Add project screenshots under `public/images/` and use `<img loading="lazy" ...>` where appropriate.
6. Update the page title and description in `index.html`.

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the portfolio repository.
4. Keep the detected Vite settings: build command `npm run build`, output directory `dist`.
5. Deploy. Every later push to the connected production branch can trigger a new deployment.
6. In the project settings, add your custom domain. Follow Vercel's DNS instructions; Vercel provisions HTTPS/SSL after DNS verification.

Netlify is also supported: import the Git repository, set build command to `npm run build`, and publish directory to `dist`.

## Challenges and solutions (document your actual experience)
- **Mobile navigation:** use a React state toggle and CSS breakpoints.
- **Initial page weight:** defer the Contact section with `React.lazy()` and `Suspense`.
- **Production performance:** use Vite's optimized production build and minification.
- **Resume path:** place the PDF in `public/` so it is served from the site root.
